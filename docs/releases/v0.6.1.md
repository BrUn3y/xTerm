# xTerm v0.6.1

xTerm detects foreground coding harnesses again on macOS and Linux. When you
run Codex or another supported CLI, the sidebar shows its harness card with
the model and activity when available. The poster returns when you exit the CLI.

The native PTY regression test exercises detection, model and activity updates,
and return to the shell through the desktop session manager.

Install the update manually using the macOS Apple Silicon DMG or ZIP, or the
Linux x64 AppImage. `SHA256SUMS.txt` covers all three downloads. macOS builds
are ad-hoc signed and may require approval on first launch.
[Apple’s installation guide](https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac)
