# xTerm v0.6.0

Remote Mode is now available in beta. Check a running terminal or respond to a
coding agent from a phone. The terminal and its processes continue to run on
the desktop.

## Remote Mode

- Enable Remote Mode from the toolbar or command palette. Choose existing
  terminals, **View only** or **Allow commands**, and an access window of
  1–5 hours.
- Scan the single-use QR to pair one device. The mobile browser restores the
  current screen and recent output. A reconnect recovers the screen without
  resending commands.
- In **Allow commands** mode, the phone can take keyboard control. The desktop
  can take it back at any time. Commands run with the desktop account’s
  permissions.
- Disable access on either device, revoke the phone on desktop, or let the
  deadline expire. xTerm closes remote access and keeps the local terminals
  running.

Remote Mode requires an existing installation of
[cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).
Keep the desktop application open and the computer online while its screen is
locked. Cloudflare terminates TLS for the public connection. Quick Tunnels are
temporary. Physical iOS Safari, Android Chrome, and cellular use still need
broader validation.

## Downloads

- macOS Apple Silicon offers a DMG and a ZIP. The app uses an ad-hoc signature.
  Apple may require approval at first launch. [Apple’s installation guide](https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac)
- Linux x64 offers an AppImage.
- `SHA256SUMS.txt` contains checksums for all three binaries.

Install updates manually. [Remote Mode walkthrough](https://brun3y.github.io/xTerm/#remote-mode)

## Validation

- Unit and native PTY coverage for QR expiration, sharing permissions, keyboard
  ownership, screen restoration, and shutdown while local terminals continue.
- The mobile browser flow was exercised in Chromium with iPhone emulation, and
  real HTTPS pairing was checked through Cloudflare Quick Tunnels.
- The release builds run macOS and Linux native clipboard tests, verify the
  extracted macOS DMG and ZIP, and generate SHA-256 checksums.
