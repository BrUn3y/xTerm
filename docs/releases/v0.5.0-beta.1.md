# xTerm v0.5.0-beta.1

Preview release, November 24, 2026. Not the recommended stable download.

## Included

- PR #8: GitHub repository icon beside the theme control. Resolves HTTPS/SSH
  remotes, prefers origin, follows active panes and subdirectories, and rejects
  stale lookup results.
- PR #10: foreground SSH sidebar with target/configuration, PID-owned transport
  information, observed process duration and per-pane lifecycle. Authentication
  and remote hostname remain Unknown/Not reported without trustworthy evidence.
- PR #9: negotiated Kitty keyboard input using pinned xterm.js 6.1.0-beta.339.
  Compatible harnesses can distinguish Shift+Enter from Enter without a global
  newline remapping. Consumed application key releases are kept out of the PTY.
- Review fixes: correct Kitty stack test expectations based on the official
  protocol and reliably terminate controlled SSH test shells.

## Validation

Local integration on Linux passed 46 unit/shell tests, strict TypeScript/Vite
build, four native PTY tests (including a controlled OpenSSH server), GitHub
and SSH native Electron checks, and the corrected keyboard stack gate. Actual
Codex CLI 0.159.3 multiline composition/editing/submission passed against a
rejecting loopback provider; no model or agent work was executed.

CI build results and artifact checks are recorded separately in the GitHub
release. Generating a macOS package does not prove physical keyboard/IME,
default-browser or macOS SSH lifecycle behavior.

## Limitations

- The terminal core is a beta dependency. Additional harnesses, multiplexers,
  physical macOS keyboards, IME/dead keys and native menu shortcuts remain
  unverified. Kitty support is not universal modifyOtherKeys support.
- macOS SSH foreground/lsof behavior still needs native user validation.
  Windows foreground SSH detection is not implemented. Dynamic SSH
  configuration cannot be safely resolved and is reported unavailable.
- PR #6 (updater) is excluded: signed macOS upgrade/signature/notarization and
  relaunch/persistence requirements remain unverified. There is no in-app
  automatic update capability in this release.
- PR #7 (Bob artwork) is excluded: the supplied official asset is unavailable.
- macOS preview builds are unsigned and not notarized, matching the previous
  public distribution policy. Do not treat them as signed updater artifacts.
  Install manually; existing v0.4.0 has no updater.
- Issues #1, #2 and #3 remain open for remaining native acceptance evidence.

## Release Build

The manually dispatched `Preview Release Build` workflow checks out an exact
commit, verifies its package version, runs unit/build/PTY checks, generates
macOS Apple Silicon DMG/ZIP and Linux x64 AppImage, and uploads CI artifacts.
It has read-only repository permission and does not publish a release.
Publication happens separately after checksums and build results are reviewed.
