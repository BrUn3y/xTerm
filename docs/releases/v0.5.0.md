# xTerm v0.5.0

Released November 24, 2026. This release brings the changes from
v0.5.0-beta.1 and v0.5.0-beta.2 to the main download.

## Highlights

- Open the active pane's GitHub repository from the toolbar. HTTPS and SSH
  remotes are supported, with updates when switching panes or directories
  (PR #8).
- Inspect foreground SSH sessions in the sidebar, including the configured
  target, owned transport information and elapsed process time. Each pane
  tracks its own connection lifecycle (PR #10).
- Compatible terminal applications can negotiate the Kitty keyboard protocol
  and distinguish Shift+Enter from Enter. Applications that do not negotiate
  enhanced input retain their existing behavior (PR #9).
- The Bob HARNESS card uses IBM's official artwork, bundled for offline use
  with attribution and an asset checksum. Both appearance modes preserve the
  original artwork's proportions and colors (PR #7).

## Downloads and installation

- macOS Apple Silicon (arm64): DMG installer and ZIP archive.
- Linux x64: AppImage.
- `SHA256SUMS.txt`: SHA-256 checksums for all three downloads.

Install updates manually. macOS builds are unsigned and not notarized, as in
v0.4.0. The in-app updater remains in development and is excluded from this
release. Existing appearance preferences and saved folders use the same
application data location; running terminal processes are not restored after
closing the application. Windows binaries are not included.

## Validation

- 47 unit/component/shell tests, the bundled artwork hash check and strict
  TypeScript/Vite production build passed locally on macOS Apple Silicon.
- Three native PTY tests passed for zsh, bash and foreground harness detection;
  the Linux-only controlled SSH-server test was skipped locally.
- Release binaries are built in CI from the exact source commit, with unit,
  build and native PTY checks on macOS arm64 and Linux x64. Artifact hashes
  are checked against each platform's manifest before publication.
- The source commit and successful CI build are linked in the GitHub release.

## Known limitations

- The terminal core is pinned to xterm.js 6.1.0-beta.339. Physical keyboards,
  IME/dead keys, native menu shortcuts, additional harnesses and multiplexers
  still need broader validation. Kitty support does not imply universal
  modifyOtherKeys support.
- SSH authentication and the remote hostname remain unknown without
  trustworthy evidence. Windows foreground SSH detection and dynamic SSH
  configuration resolution are unavailable.
