# xTerm v0.5.0-beta.2

Preview release, November 24, 2026. The recommended stable download remains v0.4.0.

## Changes

- The Bob HARNESS card now displays IBM's official artwork instead of the `b_`
  monogram (PR #7, closes #4). The original image is bundled locally, retains
  its proportions/colors in both themes and works without a network connection.
  The package includes IBM attribution and the asset's SHA-256 in NOTICE.
- Includes beta.1's GitHub repository link, foreground SSH sidebar and negotiated
  Kitty keyboard input with xterm.js 6.1.0-beta.339.

## Validation

- macOS Apple Silicon: 47 unit/component tests, exact artwork/hash check,
  TypeScript/Vite build and real zsh/bash/harness PTY checks passed. The optional
  controlled SSH-server fixture was not enabled locally (3 PTY pass, 1 skip).
- Official artwork passed compact/expanded Light/Dark UI checks at 1480x940,
  980x620 and 780x720 with no external requests or page errors.
- Native Electron development and unsigned macOS arm64 package smoke passed
  with networking blocked, isolated user-data and a controlled Bob-named process.
  The decoded image was read from app.asar and matched the official IBM hash.
  IBM Bob CLI itself and model providers were not invoked.
- CI rebuilds the exact tagged source for macOS arm64 DMG/ZIP and Linux x64
  AppImage, checks unit/native PTY tests and verifies artifact checksums before
  publishing. The successful build is linked below by the publishing workflow.

## Limitations and Installation

- macOS artifacts are unsigned and not notarized. Install manually; Apple
  signing/notarization is still required for the planned updater distribution.
- PR #6 remains draft and excluded. This release does not provide in-app updates.
- The terminal core remains a beta dependency. Additional harnesses, multiplexers,
  physical keyboards, IME/dead keys and native menu shortcuts need further testing.
  Kitty support does not imply universal modifyOtherKeys support.
- SSH authentication/remote hostname remain unknown without trustworthy evidence;
  Windows foreground SSH detection and dynamic SSH config resolution are unavailable.
- Appearance preferences and saved folders remain in the existing user-data path.
  Terminal processes are not restored after closing the app.

Downloads include macOS Apple Silicon DMG/ZIP, Linux x64 AppImage and
`SHA256SUMS.txt`. Verify the downloaded binary against that manifest before installing.
