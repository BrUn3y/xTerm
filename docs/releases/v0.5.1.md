# xTerm v0.5.1

Released November 24, 2026. Fixes terminal text paste and the integrity of the
macOS application bundle distributed in v0.5.0.

## Fixes

- Cmd+V, Cmd+Shift+V and Ctrl+Shift+V paste clipboard text into the focused
  terminal without leaking a Kitty keyboard shortcut to Codex or other coding
  agents. Multiline text stays editable until submitted; bracketed paste,
  Unicode, native text fields and Edit > Paste are preserved (PR #16).
- macOS packages now receive a complete ad-hoc code signature. The previous
  release explicitly skipped signing and failed `codesign --verify --deep
  --strict`. DMG and ZIP verification now checks the extracted application's
  signature, version, startup, real terminal and clipboard behavior before
  artifacts can be published.

## Downloads and installation

- macOS Apple Silicon (arm64): DMG installer and ZIP archive.
- Linux x64: AppImage.
- `SHA256SUMS.txt`: SHA-256 checksums for all three downloads.

Install updates manually. macOS builds are ad-hoc signed, without an Apple
Developer ID or notarization. macOS can still block the first launch; follow
[Apple's instructions for approving the application in Privacy & Security](https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac).
The ad-hoc signature fixes bundle integrity; it does not establish a verified
developer identity. The in-app updater remains in development. Windows binaries
are not included.

## Validation

- 50 unit/component/shell tests and the TypeScript/Vite production build.
- Native PTY tests for zsh, bash and foreground harness detection on macOS;
  the controlled SSH-server test additionally runs on Linux.
- Native Electron clipboard/IPC/PTY regressions on macOS and Linux, covering
  multiline and Unicode input, legacy and Kitty keyboard modes, empty/image-only
  clipboards, independent panes, delayed/failed reads and native text fields.
- macOS DMG and ZIP are opened independently, their bundle signatures are
  verified, and the full clipboard regression runs against each packaged binary
  with isolated application data.
- Artifact SHA-256 hashes are verified before publication. The exact source
  commit and build evidence are linked below in the published release.

## Known limitations

The terminal core remains xterm.js 6.1.0-beta.339. Physical keyboard layouts,
IME/dead keys, additional harnesses and Windows still need broader validation.
SSH authentication and the remote hostname remain unknown without trustworthy
evidence. See [v0.5.0](v0.5.0.md) for the other features and limitations.
